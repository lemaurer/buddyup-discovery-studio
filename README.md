# BuddyUp Discovery Studio

A static research workspace with 12 discovery-page wireframes, 24 reusable building blocks, and 32 Mobbin reference screenshots.

## Use

Open index.html, or serve this directory with `python3 -m http.server 8842`.

- Favorite blocks and filter them in the composer.
- Add, reorder, and remove sections.
- Save named screens, reopen them, update them, or save a new variation.
- Compare full-page concepts and inspect their source references.

Favorites, draft composition, shortlist, and saved screens use the visitor's browser localStorage. They are not uploaded or shared between visitors. Data is separate for each browser/device and site origin; clearing site data removes it. No backend, login, tracking, or shared database is used.

Internal wireframe actions are illustrative. The study does not book activities or run matching.

Reference screenshots retain the designs of their respective apps. Each is credited with a link to the exact Mobbin source screen; these are research references, not original BuddyUp artwork.
